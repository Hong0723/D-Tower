# Open-Source

2D 타워 디펜스 게임

배포 사이트 : https://hong0723.itch.io/d-tower


# 사용자 시나리오

1. README 파일에 존재하는 링크에 가서 게임을 다운로드 한다.

2. Zip 파일을 압축해제 하고 D-tower.exe 파일을 실행 한다.

3. Game Start 혹은 Login 버튼을 눌러 Email 칸에 이메일 형식으로 아이디를 적고, 비밀번호 설정 후 닉네임을 적는다.

4. 그 후 회원가입을 누르고 로그인을 바로 누르면 메인 메뉴창으로 다시 가게 되는데 거기서 Game Start 버튼을 누르면 게임 진행이 가능 하다.

5. 튜토리얼이 한번씩은 켜질탠데 혹시 모르니 플레이 방식에 대해 간략하게 설명하자면 30라운드로 진행 되며 10, 20, 30 라운드에 보스 몬스터가 나타난다. Player의 총 Hp 는 10이며 일반 몬스터를 못잡을시 -1, 보스 몬스터시에는 -10 으로 바로 게임이 종료 된다.

6. 흰색 노드를 클릭하면 타워 설치가 가능하고 스킬 버튼을 누를시에 스킬을 사용 할 수 있다. 

7. 우측에 x1, x2, x4, x8, x16 버튼을 통해 배속 조절을 할 수 있고 준비 Round 에는 스킵 버튼을 통해 준비시간을 스킵할 수 있다. 

8. 옵션을 누르게 되면 게임이 일시 정지 되며 우측 상단에 게임 소리 버튼이 있는데 그 버튼을 누르면 게임 소리를 끌 수 있다.

9. 이후에 게임 실패시 재도전하거나 메인 메뉴로 갈 수 있고, 게임 클리어시 자신이 초기에 설정한 닉네임으로 현재 점수에 대해 랭킹에 올라가게 된다.
